# Polynomial Curve Fitting and Curve Plotting

A MATLAB program for polynomial curve fitting and plotting, developed during my **Level 2, Term 2** studies at **Bangladesh University of Engineering and Technology (BUET)**.

## Overview

This repository contains the complete MATLAB program I used for polynomial curve fitting. The program takes a set of independent and dependent variable values, fits a polynomial of a user-specified order, and plots the resulting curve together with the original data points.

The polynomial fitting and plotting problem was a part of our coursework. I independently developed a specific part of it and that was the **curve-generation and plotting procedure**. After obtaining the polynomial coefficients, I generated a dense set of \(x\)-values and wrote the loop-based procedure to evaluate the polynomial at each point and produce the fitted curve.

For a polynomial

$$
y(x)=c_1+c_2x+c_3x^2+\cdots+c_nx^{n-1},
$$

the curve was generated by directly evaluating each term:

```matlab
sum(1,q)=sum(1,q)+c(p,1)*(xp(q)^(p-1));
```

The resulting values were then plotted together with the original data.

## My Implementation

The curve-generation part of the program is:

```matlab
xp=linspace(min(x),max(x),1000);
t=length(xp);
sum=zeros(1,t);

for p=1:n
    for q=1:t
        sum(1,q)=sum(1,q)+c(p,1)*(xp(q)^(p-1));
        yp(q)=sum(1,q);
    end
end

plot(x,y,'*',xp,yp,'k-')
grid on
```

Here, 1000 equally spaced points are generated between the minimum and maximum values of the original \(x\)-data. The polynomial is then evaluated at each point using the obtained coefficients, producing the points used for the fitted curve.

## A Small Lesson from the Project

When I developed the curve-generation part of this program, I was not aware that MATLAB already provided built-in functions such as `polyfit` and `polyval` for polynomial fitting and evaluation.

I initially approached the problem by translating the polynomial expression directly into MATLAB and writing the evaluation procedure using loops. I later discovered that the same tasks could be performed much more conveniently using MATLAB's built-in functions.

I have kept the original implementation because it represents an early experience of independently translating a mathematical expression into a working computational procedure.
